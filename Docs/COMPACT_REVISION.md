# Compact revision change record

The user authorized retaining the original and rearranging a new smaller version.

- Original: 125 × 110 mm, six switches in a horizontal row.
- Current: 95 × 95 mm, two rows of three full-size switches.
- Top row: SW1 UP, SW3 TIME SET, SW5 SNOOZE.
- Bottom row: SW2 DOWN, SW4 CLOCK SET, SW6 ALARM ON.
- Same electrical schematic, GPIO allocation, component values and logical switch matrix.

- Matching new carrier, front panel and display holder. The normal kit keycaps replace the tall custom extensions in this revision only.
- Decorative source preserved; revised body remeshed on a 1 mm grid before adding functional geometry. Small decorative features can differ.

- New routing, CAD repair/mounts and documentation were produced with substantial AI assistance, disclosed in the README.

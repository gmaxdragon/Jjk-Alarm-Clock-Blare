# Original 125 x 110 mm JJK Alarm

The original six-in-a-row electrical design, Gerbers, firmware, available CAD and previous README are preserved here. The manifest records the original bytes before the compact package was applied.

These are history files, not the current 95 mm production set. Tall keycap extensions belong to this original version. Original uploaded images remain unchanged in the root Docs/Images directory.
